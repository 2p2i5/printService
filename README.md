# printService
A program with a local webpage to get a Raspberry Pi to locally print and fix my printer's wifi issues.

My printer's wifi leads to communication errors half the time, and so I am making this to be able to print easily.
The idea is for a local computer to send the Raspberry Pi a file and for it, through the cable, to print the file.

# Requirements
You might have to manually download node in order to run the javascript.
You may also need to run `npm install` in the root directory to install dependencies.
I am using a Raspberry Pi B+ v1.2 with Debian
